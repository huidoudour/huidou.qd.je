功能总结

  • 新功能Dhizuku 免 Root 静默安装 — 通过 Hidden API Binder 调用系统 IPackageInstaller，实现无 Root 环境下的 APK 安装
  • 新功能三模式安装架构 — 支持 Shizuku / Dhizuku / 系统安装器三种安装方式，可按需切换
  • 新功能Hidden API 模块化 — 将 IIntentSender、IPackageInstaller、ServiceManager 等 11 个隐藏接口独立为 hidden-api 库模块
  • 新功能接口文档 Demo App — 在 hidden-api 模块内创建独立 Demo 应用，展示所有隐藏 API 的文档信息
  • 新功能安装对话框 — 全新的安装确认弹窗 UI，展示包名、版本、权限等信息
  • 新功能原生崩溃捕获 — 集成 C++ crash_handler，捕获 SIGSEGV/SIGABRT 等信号，保存崩溃日志到本地
  • 新功能ACRA 崩溃报告 — 接入 ACRA 框架，自动收集 Java 层异常并写入本地文件
  • 新功能主题管理 — 新增 ThemeManager，支持应用内主题切换及夜间模式配色
  • 重构包结构重组 — Java 文件按 ui/util 包分类，移除彩蛋功能，入口改为 Toast 提示
  • 重构依赖管理优化 — 新增 hidden-api 库模块依赖，更新 Gradle 版本目录
  • 优化UI 全面优化 — 清理冗余 Drawable 资源，统一图标命名，精简按钮选择器样式
  • 修复Process.killProcess 编译错误 — 修复 Java 解析到 java.lang.Process 的问题，改为全限定 android.os.Process
  • 修复语言切换功能修复 — 修正 LanguageManager 逻辑，确保多语言正确切换和持久化
  • 修复IIntentSender 类型转换 — 通过 AIDL 定义解决 ClassCastException 问题
  • 国际化多语言支持完善 — 新增繁体中文 (zh-HK/TW) 翻译，更新英文/日文/俄文翻译
